# Horizon Store

Meta Horizon Store listing metadata for the Meta Quest build of Edendale
(HORIZON.md Section F), in the same spirit as `Play Console/` on `android`:
the source copy the owner pastes into the Meta Horizon Developer Dashboard,
plus the reviewer notes and the answers the dashboard's questionnaires need.

Nothing here is a credential and nothing here is built into the app. The art
(F.2: hero, covers, icon, logo, five 2560×1440 screenshots) is produced
separately and isn't in git.
