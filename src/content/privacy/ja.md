## このポリシーの対象

このポリシーは、Apple デバイス（iPhone、iPad、Mac、Apple TV、Apple Vision Pro）、Android（Meta Quest ヘッドセットを含む）、Windows 向けの Edendale アプリと、このウェブサイト（edendale.babasama.com）を対象とします。Edendale は無料のオープンソースプロジェクトで、[github.com/Ju-Long/Edendale](https://github.com/Ju-Long/Edendale) で公開して開発しています。「私たち」とは、Edendale を開発している人々を指します。

## 私たちはあなたのデータを収集しません

Edendale にはアカウントの仕組みがなく、アプリから情報を受け取るサーバーも運用していません。アプリには解析、広告、トラッキング、クラッシュレポートのためのコードは含まれていません。あなたの情報が私たちに届くことはないため、販売、貸与、共有するものは何もありません。

デバイスで App 開発者との診断データの共有を許可している場合、Edendale を入手したストア（Apple、Google、Meta、Microsoft）が、それぞれのプライバシーポリシーに基づいて、クラッシュレポートや集計された利用統計を私たちに提供することがあります。これらは問題の修正にのみ使います。

## デバイスに残るもの

- **ライブラリ**：追加したフォルダとソース、そこで Edendale が見つけたファイルの名前・サイズ・日付・再生時間、そして各ファイルが照合された映画やエピソード。
- **設定**：再生、オーディオ、映像、字幕、操作の設定。作品ごとに記憶される選択も含みます。
- **ダウンロードした字幕**。
- **保存したログイン情報とリンクしたアカウント**：サーバーのパスワード、S3 のアクセスキー、クラウドのサインイントークン（同期先のログイン情報を含む）、TMDB のサインイン、字幕の API キー。システムの保護されたストレージに保管されます。Apple デバイスではキーチェーン、Android では Android Keystore で暗号化されたストレージ、Windows では Windows データ保護（DPAPI）を使います。有効期間の短いアクセストークンはメモリ上にのみ保持されます。
- **ペアレンタルコントロール**：「年少者向け」の設定。Android と Meta Quest では、これに加えて年齢制限の上限、そのほかのペアレンタルコントロールの設定、ペアレンタル PIN。PIN は、ソルトを付けた低速なハッシュとしてのみ保存されます。Edendale がこれらを同期したり、別のデバイスに送ったり、そのほかの場所に送ったりすることはありません。デバイス自体のバックアップに「年少者向け」の設定が残ることはありますが、PIN や年齢制限の上限が残ることはありません。
- **デバイスに表示されるもの**：視聴中の作品は、そのアートワークや進み具合とともに、アプリの外にも表示されることがあります。Edendale のウィジェット、Apple TV のトップシェルフ、Windows のタスクバーのジャンプリスト、再生中のシステムのメディアコントロール、そして**ホーム画面に「視聴を続ける」を表示**をオンにした場合は Android TV の「視聴を続ける」の列です。この列は、テレビのホーム画面アプリが読み取ることができます。デバイスを見ることができる人なら誰でも、そこで表示を見ることができます。

Edendale は、オンラインサービスに接続する前に、デバイス上でファイル名を読み取って映画やエピソードを判別します。動画をどこかにアップロードすることはありません。

## 同期されるものと、その経路

Edendale は、あなたが管理するサービスを通じて、あなたがオンにした場合にのみ同期します。

- **デバイス間の同期（Edendale 27.1 以降）**：視聴履歴を、あなたが選んだストレージを通じて同期します。詳しくは次のセクションで説明します。
- **Apple デバイス**：iCloud を使うと、視聴の進み具合、評価、レビュー、お気に入り、ウォッチリストが、あなたの非公開の iCloud データベースを通じて同期されます。リンクしたアカウント、保存したログイン情報、TMDB のサインイン、字幕の API キーは、iCloud キーチェーンを通じて iPhone、iPad、Mac、Apple Vision Pro に同期されます。Apple TV は独自のコピーを保持します。デバイス自体のバックアップには、ほかのアプリと同じように Edendale のデータも含まれます。
- **Windows**：Edendale 27.1 より前は、PC で OneDrive が設定されていれば、Edendale が視聴の進み具合と作品の状態を、あなた自身の OneDrive の `Apps/Edendale` フォルダを通じてコピーしていました。ログイン情報とアカウントがデバイスの外に出ることはありませんでした。Edendale 27.1 ではこのコピーをやめ、それらのファイルを一度だけ読み込んでそのまま残し、そのフォルダを同期先として提案します。あなたが同意するまで、同期はオフのままです。
- **Android**：Android 自体のバックアップに、ライブラリ（リンクした各ソースが属するアカウントのメールアドレスまたは名前を含む）、視聴データ、アプリの設定（「年少者向け」を含む）が含まれることがあります。ログイン情報、キー、アカウントのトークン、同期の設定、ペアレンタル PIN、そのほかのペアレンタルコントロールは、バックアップとデバイス間の転送から除外されます。
- **Meta Quest**：ヘッドセットの設定でクラウドバックアップがオンになっている場合、Meta のバックアップは Android のバックアップの仕組みを使い、除外対象も同じです。ヘッドセットからアプリを削除すると、アプリがそこに保存したものはすべて削除されます。Meta はバックアップを保持し、Edendale を再インストールすると最新のものを復元します。バックアップは、ヘッドセットの設定のクラウドバックアップから削除するまで残ります。詳しくは [Meta のクラウドバックアップに関するヘルプ](https://www.meta.com/help/quest/399621398228171/)をご覧ください。
- **TMDB アカウント（任意）**：The Movie Database にサインインすると、Edendale はお気に入り、ウォッチリスト、評価をそのアカウントと同期します。視聴の進み具合が TMDB に送られることはありません。

## デバイス間の同期

Edendale 27.1 以降では、**設定 → 同期**で、視聴履歴をすべてのデバイスでそろえることができます。同期は、あなたがオンにして保存場所を選ぶまでオフのままです。Edendale は引き続きサーバーもアカウントの仕組みも持ちません。デバイスどうしは、あなたがすでに持っているストレージを通じてのみ履歴を共有します。

- **同期ファイルの内容**：各デバイスは `Edendale/<スペース名>/<デバイス ID>.json` というファイルを 1 つ書き込みます。その中身は、視聴の進み具合と視聴済みかどうか、評価、レビュー、お気に入り、ウォッチリストの状態（いずれも作品の TMDB ID で識別し、最後に変更された時刻と変更したデバイスを記録）、スペース名、デバイスの名前とプラットフォーム、同期のために作られたランダムな ID、そして Edendale のバージョンです。ライブラリ、ファイル名やパス、ログイン情報、TMDB のセッション、ペアレンタルコントロールが含まれることはありません。
- **保存場所**：あなたが選び、あなたが所有する場所に保存されます。デバイス上のフォルダ（iCloud Drive や、ほかのクラウドアプリが提供するフォルダを含む）、Apple デバイスでは Edendale 専用の iCloud Drive フォルダ、あなたの Google Drive、OneDrive（アプリフォルダ `Apps/Edendale` 内）、Dropbox、またはあなた自身の WebDAV、SMB、SFTP サーバーです。各デバイスはそこでほかのデバイスのファイルを読み取り、デバイス上で統合します。ファイルは読める形式のシンプルな JSON なので、そのフォルダやアカウントを開ける人は誰でもあなたの視聴履歴を読むことができます。Edendale は、保存場所を選ぶときにそのことをお知らせします。
- **同期をやめるには**：**設定 → 同期**の**オフにする**を選ぶと、そのデバイスでの同期が止まり、そのデバイスのファイルを削除するかどうかを選べます。デバイス上の履歴は残ります。**設定 → 同期**でデバイスを削除すると、そのデバイスのファイルが削除されます。作品の進み具合を消去するか、Android で**視聴履歴を削除**を選ぶと、そのデバイスから消去され、同期がオンの場合は、ほかのデバイスでも次の同期時に消去されます。その後、古いコピーによって履歴が戻らないよう、同期ファイルには削除した作品ごとの印（進み具合は含まない）が最長 1 年間残ります。すべてを削除するには、すべてのデバイスで同期をオフにし、ストレージから `Edendale` フォルダを削除してください。
- **別の端末を設定する**：**別の端末を設定**を選ぶと、同期先とそのログイン情報、そしてあなたがチェックしたほかのアカウントやログイン情報が、ローカルネットワークを通じて、あなたのデバイスから別のデバイスへ直接送られます。一方のデバイスが QR コードを表示し、もう一方がそれをスキャンするかリンクとして開きます。両方のデバイスが対応している場合は、表示されたコードをもう一方で入力することもできます。2 台のデバイスはそれを使って接続を暗号化する鍵を取り決め、送信側のデバイスは、何かを送る前に相手のデバイス名の確認を求めます。私たちやほかの誰かを経由することはありません。iPhone、iPad、Android のスマートフォンとタブレット、Meta Quest 3 と 3S では、カメラでコードをスキャンできます。Edendale がカメラへのアクセスを求めるのは、あなたがスキャンを選んだときだけです。コードはデバイス上で読み取られ、カメラの映像が保存されたり送られたりすることはありません。ペアリング画面を開いている間、デバイスはもう一方のデバイスが見つけられるように、ローカルネットワーク上に自分の名前とプラットフォームを知らせます。Google のサインインを移せないプラットフォームの間では、Google アカウントのメールアドレス、スペース名、同期フォルダの ID だけが送られ、新しいデバイスではあなた自身が Google にサインインします。
- **削除したデバイス**は、受け取ったログイン情報とすでに持っている履歴を、ストレージのサービスで Edendale のアクセスを取り消すか、サーバーのパスワードを変更するまで保持します。

## Edendale が使うオンラインサービス

以下の各サービスには、通常のインターネット接続と同様にデバイスの IP アドレスが送られるほか、次の情報が送られます。

- **[TMDB](https://www.themoviedb.org/privacy-policy)**（The Movie Database）：映画やドラマの情報、画像、年齢区分のため。Edendale がファイル名から読み取ったタイトル（年を含むこともあります。完全なファイル名、フォルダ、ファイルそのものは送りません）、検索欄に入力した語句、閲覧した作品や Edendale が情報を調べる作品の TMDB ID。サインインしている場合は TMDB のセッションも送られます。
- **[Wyzie Subs](https://wyzie.io/privacy)**：オンラインで字幕を検索したときだけ。作品の TMDB ID、シーズン番号とエピソード番号、Edendale が求める言語と字幕の形式、聴覚障害者向け字幕を含めるかどうか、そして API キー（あなたが入力した場合はあなたのキー、それ以外は Edendale 自身のキー）。
- **[TheIntroDB](https://theintrodb.org/docs/privacy)**：スキップボタンがオンのときだけ（初期設定はオフ）。作品の TMDB ID、シーズン番号とエピソード番号、動画の長さ。
- **[YouTube](https://policies.google.com/privacy)**：予告編の再生を選んだときだけ。Apple TV 以外の Apple デバイスと、Meta Quest 以外の Android デバイスでは、YouTube のプライバシー強化モード（youtube-nocookie.com）で再生します。Apple TV では YouTube アプリで予告編を開き、Windows ではブラウザで youtube.com の予告編を開き、Meta Quest ではブラウザまたは YouTube アプリで開きます。
- **リンクしたストレージ**と、同期のために選んだストレージ：次のセクションで説明します。

## リンクしたストレージ

Edendale は、デバイス上のフォルダや、リンクしたストレージ（SMB、NFS、SFTP、WebDAV の各サーバー、S3 互換ストレージ、Google Drive、OneDrive、Dropbox）から動画を再生します。利用できるサービスはプラットフォームによって異なります。すべての接続は、デバイスから選んだサービスへ直接行われます。私たちが運用するサーバーを経由するものはありません。

- **サインイン**：Google Drive、OneDrive、Dropbox では、OAuth 2.0（PKCE 使用）により各サービス自身のページでサインインするため、Edendale があなたのパスワードを見ることはありません。サーバーのログイン情報（ユーザー名、パスワード、アクセスキー）は、そのサーバーにだけ送られます。
- **限定されたアクセス**：Google に求めるのは `drive.file` だけで、その対象は Google 自身のファイル選択画面で選んだ動画と Edendale が作成したファイルに限られ、Drive 内のほかのものは含まれません。Microsoft は `Files.Read`、`Files.ReadWrite.AppFolder`、`User.Read`、`offline_access`。Dropbox は `account_info.read`、`files.metadata.read`、`files.content.read`、`files.content.write`。Edendale は動画を読み取るだけで、動画やストレージ内のほかのものをアップロード、変更、共有、削除することはありません。Edendale が書き込んだり削除したりするのは自身の同期ファイルだけで、それも同期をオンにした場合に限られます。対象は、Google Drive、Dropbox、またはあなたが選んだサーバーやフォルダにある `Edendale` フォルダと、OneDrive のアプリフォルダです。
- **Edendale が読み取るもの**：アカウントの表示とソースの区別のための、アカウントの ID、メールアドレス、名前。閲覧・リンクした場所にあるファイルとフォルダ（Google Drive では選んだ動画）の名前・サイズ・日付・再生時間。再生している間だけ動画の内容。そして、同期をオンにした場合は、あなたのデバイスの同期ファイル。
- **Edendale が保持するもの**：ファイルの情報はデバイス上のライブラリの一部になります。サインイントークンとログイン情報は、前述の保護されたストレージに保管されます。動画データは再生中にメモリ上に置かれるだけで、ディスクに保存されることはありません。
- **テレビ**：Apple TV は iPhone または iPad から、Android TV はほかの Android デバイスの Edendale から、ローカルネットワーク上の暗号化された接続を通じてアカウントやログイン情報を受け取ることができます。これは、テレビで転送を開始し、もう一方のデバイスで確認した場合に限られます。Android TV は、待機している間、ローカルネットワーク上に自分の名前を知らせます。テレビでは、別のデバイスで承認するコードを使って OneDrive にサインインすることもできます。Edendale 27.1 以降では、「デバイス間の同期」で説明したとおり、どのデバイスからでも同じ方法で別のデバイスを設定できます。

## Google ユーザーデータ

Google Drive をリンクするときは、Google 自身のファイル選択画面で動画を選びます。この画面は、サインイン時と、**ほかのビデオを選択**を使うたびに開きます。同期ファイルを保存するためだけに Google Drive にサインインする場合、この画面は開きません。Edendale は次の情報にアクセスします。

- 選んだ動画（`drive.file`）。Google Drive 内のほかのものにはアクセスしません。Edendale はそれらを一覧表示し、名前・サイズ・日付・動画の長さを読み取り、再生を選んだ動画をストリーミングします。Google は選んだ動画を Edendale の各アプリの間で共有するため、あるデバイスで選んだ動画が、同じ Google アカウントでサインインしている別のデバイスにも表示されることがあります。
- Google Drive を同期に使う場合は、`Edendale` フォルダと、Edendale 自身がそこに作成する同期ファイル。Edendale は「デバイス間の同期」で説明したとおり、それらを読み取り、置き換え、削除します。
- Google Drive が同じ権限で提供する、Google Drive のユーザー ID、メールアドレス、アカウント名。リンク中のアカウントを表示し、複数のアカウントを区別するために使います。

Edendale がこれらのデータを使うのは、Google Drive ソースの機能（選んだ動画の一覧表示と再生）を提供するためと、あなたが選んだ場合に Drive 内の同期ファイルを管理するためだけです。動画や Drive 内のほかのファイルをアップロード、変更、共有、削除することはありません。他のソースと同じく、Edendale はデバイス上でファイル名を読み取って映画やエピソードを判別し、情報を取得するために、判別したタイトル（年を含むこともあります）だけを TMDB に送ります。

データはあなたのデバイスと、あなた自身の Drive に残ります。ファイルの情報はライブラリに、リンクしたアカウント（ID、メールアドレス、名前、サインイントークン）は前述の保護されたストレージに保管されます。Apple デバイスでは、iCloud キーチェーンによってアカウントがほかの Apple デバイスに同期されます。別のデバイスに届くのは、あなたのデバイスからの転送を確認したときだけです。Google のサインインを移せないプラットフォームの間では、メールアドレスと同期フォルダの ID だけが送られます。ライブラリから動画を削除すると、Edendale はその動画が再び一覧に表示されないよう、そのデバイスにだけファイル ID を保持することがあります。Google ユーザーデータが私たちや私たちの運用するサーバーに送られることはないため、私たちがそれを見たり読んだりすることはありません。販売されることも、広告に使われることも、人工知能や機械学習のモデルの開発、改良、トレーニングに使われることもありません。

Edendale のアクセスを終了するには、ソースを削除し（ライブラリからそのファイルも削除されます）、**設定 → アカウント**でサインアウトしてください。**サインアウトしてアクセスを取り消す**（Windows では**サインアウト**）を選ぶと、Google での Edendale のアクセス権も取り消されます。[Google アカウントのサードパーティとの接続](https://myaccount.google.com/connections)から、いつでもアクセスを削除できます。アクセスを取り消すと、テレビを含むすべてのデバイスでアクセスが終了し、Google は選んだ動画の情報を消去します。Edendale が作成した同期ファイルは、あなたが削除するまで Drive に残ります。アプリを削除すると、そのデバイスにアプリが保存したものはすべて削除されます。Android や Meta Quest のバックアップに、動画の属するアカウントのメールアドレスまたは名前を含むライブラリのコピーが残ることはありますが、アカウントのサインイントークンが残ることはありません。

Edendale による、Google API から受け取った情報の使用およびほかのアプリへの転送は、限定使用（Limited Use）の要件を含む [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)（Google API サービスのユーザーデータに関するポリシー）に準拠します。

## Microsoft と Dropbox のアカウント

OneDrive と Dropbox もほぼ同じ仕組みです。閲覧・リンクしたフォルダへの読み取りアクセスは、動画の一覧表示と再生にだけ使われます。どちらかを同期に使う場合の書き込みアクセスは、Edendale 自身の同期ファイルにだけ使われ、対象は OneDrive のアプリフォルダ（`Apps/Edendale`）または Dropbox の `Edendale` フォルダです。Edendale がそこにあるほかのものを変更したり削除したりすることはありません。アカウント情報とサインイントークンは、あなたのデバイスにだけ保管されます。**設定 → アカウント**でサインアウトしてください。Apple デバイスと Android では、**サインアウトしてアクセスを取り消す**を選ぶと、Dropbox での Edendale のアクセス権も取り消されます。[Microsoft アカウントにアクセスできるアプリ](https://account.live.com/consent/Manage)や [Dropbox の連携アプリ](https://www.dropbox.com/account/connected_apps)から Edendale を削除することもできます。同期ファイルは、あなたが削除するまでストレージに残ります。職場または学校の Microsoft アカウントは、組織が管理している場合があります。

## このウェブサイト

このウェブサイトは GitHub Pages でホストされている静的サイトです。Cookie を設定せず、ブラウザに何も保存せず、フォームもなく、ほかのサイトから解析ツール、フォント、スクリプトを読み込むこともありません。何も保存せずにブラウザの設定から言語を選び、あなたが選んだ言語はページのアドレスにだけ反映されます。ホスティング事業者である GitHub は、IP アドレスなどリクエストに伴う一般的な情報を受け取ります。詳しくは [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) をご覧ください。Edendale アプリを開くリンクは、あなたのデバイス上で処理されます。

## お子様について

Edendale は、お子様を含め、どなたの個人情報も意図的に収集することはありません。アプリは私たちに何も送らないため、私たちが収集できるものはありません。

## あなたが選べること

アプリでは、いつでもデータを確認、変更、削除できます。ソースの削除、アカウントからのサインアウト、デバイス間の同期、iCloud 同期、デバイスのバックアップのオフ、ストレージからの同期ファイル（Windows では以前の OneDrive のコピーも）の削除、アプリの削除が可能です。私たちはあなたの個人データを一切保有していないため、これらの操作が、アクセスや削除の権利を行使する方法となります。上記のサービスが保持するデータには、それぞれのプライバシーポリシーが適用されます。
