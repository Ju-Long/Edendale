## このポリシーの対象

このポリシーは、Apple デバイス（iPhone、iPad、Mac、Apple TV、Apple Vision Pro）、Android、Windows 向けの Edendale アプリと、このウェブサイト（edendale.babasama.com）を対象とします。Edendale は無料のオープンソースプロジェクトで、[github.com/Ju-Long/Edendale](https://github.com/Ju-Long/Edendale) で公開して開発しています。「私たち」とは、Edendale を開発している人々を指します。

## 私たちはあなたのデータを収集しません

Edendale にはアカウントの仕組みがなく、アプリから情報を受け取るサーバーも運用していません。アプリには解析、広告、トラッキング、クラッシュレポートのためのコードは含まれていません。あなたの情報が私たちに届くことはないため、販売、貸与、共有するものは何もありません。

デバイスで App 開発者との診断データの共有を許可している場合、Edendale を入手したストア（Apple、Google、Microsoft）が、それぞれのプライバシーポリシーに基づいて、クラッシュレポートや集計された利用統計を私たちに提供することがあります。これらは問題の修正にのみ使います。

## デバイスに残るもの

- **ライブラリ**：追加したフォルダとソース、そこで Edendale が見つけたファイルの名前・サイズ・日付・再生時間、そして各ファイルが照合された映画やエピソード。
- **設定**：再生、オーディオ、映像、字幕、操作の設定。作品ごとに記憶される選択も含みます。
- **ダウンロードした字幕**。
- **保存したログイン情報とリンクしたアカウント**：サーバーのパスワード、S3 のアクセスキー、クラウドのサインイントークン。システムの保護されたストレージに保管されます。Apple デバイスではキーチェーン、Android では Android Keystore で暗号化されたストレージ、Windows では Windows データ保護（DPAPI）を使います。有効期間の短いアクセストークンはメモリ上にのみ保持されます。

Edendale は、オンラインサービスに接続する前に、デバイス上でファイル名を読み取って映画やエピソードを判別します。動画をどこかにアップロードすることはありません。

## 同期されるものと、その経路

Edendale は、あなたが管理するサービスを通じて、あなたがオンにした場合にのみ同期します。

- **Apple デバイス**：iCloud を使うと、視聴の進み具合、評価、お気に入り、ウォッチリストが、あなたの非公開の iCloud データベースを通じて同期されます。リンクしたアカウントと保存したログイン情報は、iCloud キーチェーンを通じて iPhone、iPad、Mac、Apple Vision Pro に同期されます。Apple TV は独自のコピーを保持します。
- **Windows**：OneDrive へのレプリケーションをオンにすると、視聴の進み具合と作品の状態が、あなた自身の OneDrive にあるフォルダを通じてコピーされます。ログイン情報とアカウントがデバイスの外に出ることはありません。
- **Android**：Android 自体のバックアップに、ライブラリと視聴データが含まれることがあります。ログイン情報、キー、アカウントのトークンは、バックアップとデバイス間の転送から除外されます。
- **TMDB アカウント（任意）**：The Movie Database にサインインすると、Edendale はお気に入り、ウォッチリスト、評価をそのアカウントと同期します。視聴の進み具合が TMDB に送られることはありません。

## Edendale が使うオンラインサービス

以下の各サービスには、通常のインターネット接続と同様にデバイスの IP アドレスが送られるほか、次の情報が送られます。

- **[TMDB](https://www.themoviedb.org/privacy-policy)**（The Movie Database）：映画やドラマの情報と画像のため。Edendale がファイル名から読み取ったタイトルと年（完全なファイル名、フォルダ、ファイルそのものは送りません）と、閲覧した作品の TMDB ID。サインインしている場合は TMDB のセッションも送られます。
- **[Wyzie Subs](https://wyzie.io/privacy)**：オンラインで字幕を検索したときだけ。作品の TMDB ID、シーズン番号とエピソード番号、希望する言語、あなたの API キー。
- **[TheIntroDB](https://theintrodb.org/docs/privacy)**：スキップボタンがオンのときだけ（初期設定はオフ）。作品の TMDB ID、シーズン番号とエピソード番号、動画の長さ。
- **[YouTube](https://policies.google.com/privacy)**：予告編の再生を選んだときだけ。Apple デバイスと Android デバイスでは、YouTube のプライバシー強化モード（youtube-nocookie.com）で再生します。Windows では、ブラウザで youtube.com の予告編を開きます。
- **リンクしたストレージ**：次のセクションで説明します。

## リンクしたストレージ

Edendale は、デバイス上のフォルダや、リンクしたストレージ（SMB、NFS、SFTP、WebDAV の各サーバー、S3 互換ストレージ、Google Drive、OneDrive、Dropbox）から動画を再生します。利用できるサービスはプラットフォームによって異なり、Google Drive は現在 Apple デバイスで利用できます。すべての接続は、デバイスから選んだサービスへ直接行われます。私たちが運用するサーバーを経由するものはありません。

- **サインイン**：Google Drive、OneDrive、Dropbox では、OAuth 2.0（PKCE 使用）により各サービス自身のページでサインインするため、Edendale があなたのパスワードを見ることはありません。サーバーのログイン情報（ユーザー名、パスワード、アクセスキー）は、そのサーバーにだけ送られます。
- **読み取り専用のアクセス**：Edendale が求めるのは読み取り専用の権限です。Google は `openid`、`email`、`drive.readonly`。Microsoft は `Files.Read`、`User.Read`、`offline_access`。Dropbox は `account_info.read`、`files.metadata.read`、`files.content.read`。Edendale がストレージ内のものを作成、変更、共有、削除することはできません。
- **Edendale が読み取るもの**：アカウントの表示とソースの区別のための、アカウントの ID とメールアドレス。閲覧・リンクした場所にあるファイルとフォルダの名前・サイズ・日付・再生時間。そして、再生している間だけ動画の内容。
- **Edendale が保持するもの**：ファイルの情報はデバイス上のライブラリの一部になります。サインイントークンとログイン情報は、前述の保護されたストレージに保管されます。動画データは再生中にメモリ上に置かれるだけで、ディスクに保存されることはありません。
- **テレビ**：Apple TV は、テレビで転送を開始し、iPhone または iPad で確認した場合にのみ、ローカルネットワーク上の暗号化された接続を通じて、それらのデバイスからアカウントやログイン情報を受け取ることができます。テレビでは、別のデバイスで承認するコードを使って OneDrive にサインインすることもできます。

## Google ユーザーデータ

Google Drive をリンクすると、Edendale は次の情報にアクセスします。

- Google アカウントの一意の ID とメールアドレス（`openid` と `email`）。リンク中のアカウントを表示し、複数のアカウントを区別するために使います。
- Google Drive 内のファイルとフォルダ（`drive.readonly`）。Edendale は、閲覧・リンクしたフォルダを一覧表示し、その中のファイルの名前・サイズ・日付・動画の長さを読み取り、再生を選んだ動画をストリーミングします。

Edendale がこれらのデータを使うのは、Google Drive ソースの機能（フォルダの選択、その中の動画の一覧表示、再生）を提供するためだけです。他のソースと同じく、Edendale はデバイス上でファイル名を読み取って映画やエピソードを判別し、情報を取得するために、判別したタイトルと年だけを TMDB に送ります。

データはあなたのデバイスに残ります。ファイルの情報はライブラリに、リンクしたアカウント（ID、メールアドレス、サインイントークン）はキーチェーンに保管され、iCloud キーチェーンによってほかの Apple デバイスに同期されます。Apple TV に届くのは、iPhone または iPad からの転送を確認したときだけです。Google ユーザーデータが私たちや私たちの運用するサーバーに送られることはないため、私たちがそれを見たり読んだりすることはありません。販売されることも、広告に使われることも、人工知能や機械学習のモデルの開発、改良、トレーニングに使われることもありません。

Edendale のアクセスを終了するには、ソースを削除し（ライブラリからそのファイルも削除されます）、**設定 → アカウント**でサインアウトしてください。**サインアウトしてアクセスを取り消す**を選ぶと、Google での Edendale のアクセス権も取り消されます。[Google アカウントのサードパーティとの接続](https://myaccount.google.com/connections)から、いつでもアクセスを削除できます。アプリを削除すると、そのデバイスにアプリが保存したものはすべて削除されます。

Edendale による、Google API から受け取った情報の使用およびほかのアプリへの転送は、限定使用（Limited Use）の要件を含む [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)（Google API サービスのユーザーデータに関するポリシー）に準拠します。

## Microsoft と Dropbox のアカウント

OneDrive と Dropbox も同じ仕組みです。アクセスは読み取り専用で、動画の一覧表示と再生にだけ使われ、あなたのデバイスにだけ保管されます。**設定 → アカウント**でサインアウトしてください。Dropbox では、**サインアウトしてアクセスを取り消す**を選ぶと、Dropbox での Edendale のアクセス権も取り消されます。[Microsoft アカウントにアクセスできるアプリ](https://account.live.com/consent/Manage)や [Dropbox の連携アプリ](https://www.dropbox.com/account/connected_apps)から Edendale を削除することもできます。職場または学校の Microsoft アカウントは、組織が管理している場合があります。

アプリでは、いつでもデータを確認、変更、削除できます。ソースの削除、アカウントからのサインアウト、iCloud 同期や OneDrive レプリケーションのオフ、アプリの削除が可能です。私たちはあなたの個人データを一切保有していないため、これらの操作が、アクセスや削除の権利を行使する方法となります。上記のサービスが保持するデータには、それぞれのプライバシーポリシーが適用されます。
